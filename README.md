# Santhiya Nagarajan — Portfolio

A responsive dark-theme personal developer portfolio.

## Run locally
Open `index.html` in a browser.

## Deploy on GitHub Pages
1. Create a repository (for example `portfolio`).
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
3. In GitHub: Settings → Pages → Deploy from a branch → `main` / root.
4. Save and wait for the Pages URL to be generated.

## Customize
Edit the text and links in `index.html`. The profile photo is in `assets/santhiya.jpg`.
